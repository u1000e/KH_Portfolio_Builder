# 포트폴리오빌더 서비스 가이드

> 개발자의 첫 번째 명함, 포트폴리오.
> 이제 혼자 고민하지 마세요. AI가 함께합니다.

---

## 1. 포트폴리오빌더란?

포트폴리오빌더는 **개발자 지망생을 위한 올인원 포트폴리오 제작 플랫폼**입니다.

취업 준비 과정에서 가장 막막한 순간이 언제인가요?
아마 빈 화면 앞에서 "내 포트폴리오, 어떻게 시작하지?"라고 고민할 때일 겁니다.

포트폴리오빌더는 그 막막함을 해소하기 위해 탄생했습니다.

### 핵심 철학

| 기존의 어려움 | 포트폴리오빌더의 해결책 |
|--------------|---------------------|
| "어떤 형식으로 만들지?" | 9가지 전문 템플릿 제공 |
| "내 포트폴리오 괜찮은 건가?" | AI 평가 시스템으로 객관적 피드백 |
| "깃허브 연동은 어떻게?" | 원클릭 GitHub 연동 |
| "다른 사람들은 어떻게 만들었지?" | 갤러리에서 우수 사례 탐색 |
| "피드백 받을 곳이 없어요" | 강사진 피드백 + 동료 댓글 시스템 |

## 2. 포트폴리오 제작 기능

### 2.1 템플릿 시스템

> 디자인 감각이 없어도 괜찮습니다.
> 검증된 9가지 템플릿이 여러분의 이야기를 담아드립니다.

| 템플릿 | 특징 | 추천 대상 |
|--------|------|----------|
| **BASIC** | 깔끔하고 심플한 기본형 | 처음 시작하는 분 |
| **MODERN** | 세련된 사이드바 레이아웃 | 트렌디한 느낌을 원하는 분 |
| **CREATIVE** | 예술적이고 창의적인 디자인 | 프론트엔드/디자인 지향 |
| **TERMINAL** | 개발자 감성 터미널 스타일 | 백엔드/DevOps 지향 |
| **MIDCENTURY** | 레트로 모던 감성 | 개성을 표현하고 싶은 분 |
| **ANALOG** | 따뜻한 아날로그 감성 | 차분한 인상을 주고 싶은 분 |
| **WINDOWS98** | 추억의 윈도우98 테마 | 재미있는 첫인상을 원하는 분 |
| **RESUME** | 정통 이력서 포맷 | 대기업/공기업 지원자 |
| **DASHBOARD** | 대시보드 스타일 구성 | 데이터 중심 프로젝트가 많은 분 |

### 2.2 포트폴리오 구성 섹션

한 번의 입력으로 완성되는 체계적인 포트폴리오 구조:

```
📋 기본 정보
   ├── 이름, 이메일, 연락처
   ├── GitHub / LinkedIn 링크
   └── 프로필 이미지

📝 자기소개
   └── 나를 표현하는 핵심 문장들

💡 기술 스택
   └── 기술별 숙련도 표시

🚀 프로젝트
   ├── 프로젝트명 및 설명
   ├── 사용 기술, 담당 역할
   ├── 주요 기능 및 회고
   └── 링크 및 썸네일

🎓 학력 / 경력 / 자격증

🔧 트러블슈팅
   ├── 문제 상황
   ├── 원인 분석
   ├── 해결 과정
   └── 배운 점
```

### 2.3 트러블슈팅 섹션

> "이 지원자는 문제를 어떻게 해결하는 사람일까?"
> 면접관이 가장 궁금해하는 부분, 트러블슈팅으로 보여주세요.

**5가지 카테고리로 체계적 정리:**
- 🐛 **Bug** - 버그 해결 경험
- ⚡ **Performance** - 성능 최적화 사례
- 🚀 **Deploy** - 배포 과정 이슈 해결
- 🔐 **Security** - 보안 관련 대응
- 💻 **Code** - 코드 품질 개선

## 3. AI 평가 시스템

### 3.1 평가 개요

> 면접관의 시선으로 포트폴리오를 점검받으세요.
> AI가 130점 만점 기준으로 객관적인 평가를 제공합니다.

**하루 5회** 평가 가능 (자정 초기화)

### 3.2 평가 항목

| 항목 | 배점 | 평가 내용 |
|------|------|----------|
| **완성도** | 30점 | 필수 섹션 작성 여부, 내용의 충실도 |
| **기술력** | 30점 | 기술 스택 다양성, 프로젝트 기술적 깊이 |
| **트러블슈팅** | 25점 | 문제 해결 과정의 논리성과 구체성 |
| **표현력** | 20점 | 문장 가독성, 전달력, 전문성 |
| **활동성** | 25점 | GitHub 기여도, 커밋 활동 |
| **합계** | **130점** | |

## 5. 갤러리

### 5.1 갤러리란?

> 혼자 만들고 혼자 보는 포트폴리오는 이제 그만.
> 갤러리에서 영감을 얻고, 동기부여를 받으세요.

갤러리는 **공개 설정된 모든 포트폴리오**가 모이는 공간입니다.

### 5.2 갤러리 기능

**정렬 옵션:**
- 🔥 **인기순** - 좋아요가 많은 포트폴리오
- 🕐 **최신순** - 최근 업데이트된 포트폴리오

**포트폴리오 카드 표시 정보:**
- 프로필 이미지 / 이니셜
- 사용자명 및 포트폴리오 제목
- 자기소개 미리보기
- 대표 기술 스택 (최대 4개)
- AI 평가 등급 (S/A 등급 배지)
- 획득 칭호 및 배지
- 좋아요 수 및 업데이트 날짜

### 5.3 소셜 기능

> 좋은 포트폴리오를 발견했다면, 응원의 마음을 전하세요.

**좋아요 시스템:**
- 마음에 드는 포트폴리오에 좋아요 ❤️
- 내가 좋아요한 포트폴리오는 마이페이지에서 확인
- 좋아요 5개 이상 받으면 숨겨진 배지 **"인기스타"** 획득

**댓글 시스템:**
- 포트폴리오에 격려/피드백 댓글 작성
- 비속어 필터링으로 건전한 소통 환경 유지
- 댓글 5개 이상 작성 시 숨겨진 배지 **"응원단"** 획득
- 댓글 5개 이상 받으면 숨겨진 배지 **"소통왕"** 획득

### 5.4 강사 피드백

> 전문가의 시선으로 한 단계 더 성장하세요.

강사진이 직접 작성하는 1:1 피드백 시스템:
- 읽음/안읽음 상태 확인
- 해결/미해결 상태 관리
- 피드백 5개 이상 해결 시 숨겨진 배지 **"성실왕"** 획득

## 7. 배지 & 칭호 시스템

### 7.1 배지 종류

포트폴리오빌더와 승철링고를 통해 획득 가능한 **70여 개의 배지**:

**소셜 활동 배지:**
| 배지명 | 조건 | 숨김 여부 |
|--------|------|----------|
| 인기스타 ⭐ | 좋아요 5개 이상 받기 | 🔒 숨김 |
| 서포터 💪 | 좋아요 10개 이상 누르기 | 🔒 숨김 |
| 응원단 📣 | 댓글 5개 이상 작성 | 🔒 숨김 |
| 소통왕 💬 | 댓글 5개 이상 받기 | 🔒 숨김 |
| 성실왕 ✅ | 피드백 5개 이상 해결 | 🔒 숨김 |

**학습 배지 (승철링고 연동):**
- 연속 학습 배지 (3일, 7일, 14일, 30일)
- 문제 풀이 배지 (10~600문제)
- 정답률 배지 (80%, 90%)
- 카테고리 마스터 배지 (13개 분야)

### 7.2 칭호 시스템

갤러리 카드에 표시되는 나만의 칭호:

| 레벨 | 칭호 |
|------|------|
| 0-19 | 입문자 🌱 |
| 20-39 | 견습생 📚 |
| 40-59 | 숙련자 💻 |
| 60-79 | 도내남바완 🔥 |
| 80-99 | 전국재패 🏴‍☠️ |
| 100 | 개발왕 👑 |

## 8. 마이페이지

**배지 탭:**
- 획득한 배지 확인

- 강사진 피드백 확인

**댓글 탭:**
- 내가 작성한 댓글 관리

**설정 탭:**
- 프로필 수정
- 계정 관리

## 9. 포트폴리오 공개/비공개

### 9.1 공개 설정

> 준비가 됐을 때, 세상에 공개하세요.

- **비공개**: 나만 볼 수 있는 상태 (기본값)

- 갤러리 노출을 통한 피드백 기회
- 좋아요/댓글 수신
- 강사 피드백 수신 가능
- S등급 달성 시 활동 피드에 공개
